# HR Analytics

A beginner-friendly HR analytics practice project using Python, Pandas, and Matplotlib.

## Objectives
- Review a sample employee dataset.
- Calculate the overall employee attrition rate.
- Compare attrition rates across departments.
- Compare average monthly income across job roles.
- Generate charts to communicate findings.

## Project files
- `hr_analysis.py` – analysis and chart-generation script.
- `data/hr_employee_data.csv` – sample synthetic dataset.
- `requirements.txt` – required Python libraries.
- `outputs/` – charts generated when the script runs.

## Run locally
```bash
pip install -r requirements.txt
python hr_analysis.py
```

## Dataset note
The included data is synthetic and created only for practice. It does not represent real employees or a real company.

## Skills practiced
Python, Pandas, data grouping, percentage calculations, and data visualization.
